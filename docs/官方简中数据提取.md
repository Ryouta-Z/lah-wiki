# 官方简中数据提取

机器人不会把游戏原始文本快照提交到 Git。请在本机已安装并完成资源下载的 Live A Hero 模拟器中提取以下三个文件，并保存在 `data/cache/lah-localization/`：

```text
ChineseSimplified-YYYYMMDD.json
CardMaster-YYYYMMDD
SkillMaster-YYYYMMDD
```

三个文件必须来自同一次提取，并使用同一个日期标识。生成器只会使用名称中的共同日期；混用不同日期的文件会被忽略。

MuMu 示例（实例序列号请以 `adb devices` 的输出为准）：

```powershell
$adb = 'E:\Program Files\Netease\MuMu\nx_main\adb.exe'
$source = '/sdcard/Android/data/jp.co.lifewonders.liveahero/files/datas'
New-Item -ItemType Directory -Force data\cache\lah-localization
& $adb -s emulator-5556 pull "$source/catalog/ChineseSimplified.json" data\cache\lah-localization\ChineseSimplified-YYYYMMDD.json
& $adb -s emulator-5556 pull "$source/master/CardMaster" data\cache\lah-localization\CardMaster-YYYYMMDD
& $adb -s emulator-5556 pull "$source/master/SkillMaster" data\cache\lah-localization\SkillMaster-YYYYMMDD
Get-FileHash data\cache\lah-localization\* -Algorithm SHA256
```

然后运行：

```powershell
uv run python scripts/fetch_lah.py
```

优先级为：官方简中描述、社区中文描述、已有机器翻译缓存、日文原文。名称只使用官方简中或社区中文；未命中的名称保留日文，避免用机翻生成不可靠的人名或技能名。

当 GitHub API 限流时，只要上述本地快照存在，生成器会直接使用本地 `CardMaster` 和 `SkillMaster` 继续生成。机器翻译服务不可用时，已缓存的译文仍会被使用，未缓存项保留日文，不会中断生成。

## 每轮解包的官中检查与确认

每次解包除新角色外，也检查原日文资料是否已有官方中文。先提供对比参考，用户确认具体条目后，才将对应 Wiki 资料替换为官方中文；未经确认不运行会改写正式资料的生成步骤。

1. 保留上一轮与本轮官方简中快照及文件哈希。全量比较新增、修改和删除键，再核对现有 Wiki 查询库与速查卡片中的日文残留。名称、说明和追加效果分别核对。
2. 通过实际角色主表、技能 ID 和状态引用关联资料。区分“本轮首次观察到官中变化”与“官中此前已存在但本地未采用”，不把文本键数或各等级记录数说成独立技能数。简中字典里的日文回退值、空值和混合日文不能称完整官中。
3. 在本轮 `outputs/` 目录生成 HTML 对照与原始证据，列出当前资料、官方中文、日文及精确来源键、缓存取得时间、待确认字段。保留原审核稿和审核意见，不自动提交或发送邮件。
4. 用户确认后只替换获确认的字段，保留日文来源与查询别名，核对主动、被动、追加效果和各阶段数值均未遗漏；同步相应查询库与速查展示，并验证关联。未确认或仍缺官中的部分保留原文/暂译。

只读审计可复用以下命令。`--cache-dir` 内需有同一轮已核验的 `ChineseSimplified.json`、`CardMaster`、`SidekickMaster`、`SkillMaster`；路径按实际轮次替换：

```powershell
.venv/Scripts/python.exe scripts/audit_lah_official_zh.py --baseline data/cache/maintenance-probe/20261001/recheck-190118/master-cache/ChineseSimplified.json --cache-dir outputs/maintenance-20261008/zh-comparison-20261009/local/20261009-103820-official-cache --output-dir outputs/maintenance-20261008/official-zh-audit-20261009
```

该脚本只写指定目录的 `audit.json`，不会改 Wiki。语言识别仅用于列出候选；纯汉字日文通过精确日文主表对照识别，合并了追加效果的装备描述须独立审核，不能拿主装备中文覆盖整段。已为中文的语义改写或漏句仍需逐句核对。
