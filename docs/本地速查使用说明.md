# Live A Hero 本地速查

当前快照可直接双击打开 [../quickref/index.html](../quickref/index.html) 使用。网页不连接网络，也不依赖 NapCat、NoneBot 或正在运行的 MuMu。

搜索支持官方简中名、日文名、卡片编号、技能名称/说明，以及 data/aliases.json 中的常用别名。例如输入“阿卡西”时，会分别显示英雄与助手卡，再选择具体卡片查看属性和技能。

搜索结果卡片和详情弹窗会显示本地头像。头像只采用 `data/images/icon/` 中已有的 PNG：优先按卡片的唯一资源代号精确匹配，没有该字段时再按日文原名、官方中文名精确匹配；没有对应头像时显示“本地暂无头像”的占位图，不会联网下载或用相近角色图片替代。

Excel 成品位于 outputs/<任务标识>/Live_A_Hero_本地速查.xlsx，包含“英雄卡”“助手卡”“技能”“技能强化”四张可筛选表。

- 英雄卡按原始名称合并，只保留同名角色的最高星卡，并只显示其 60 级 HP、攻击和速度；没有 60 级成长记录的特殊卡仍可查技能，但属性留空。
- 助手按最高阶段合并，每名助手只显示最高阶段主动技能与最高等级装备技能两张卡；有记录的追加装备效果合并在装备技能卡内。追加效果有文本时会单列显示；为空或与装备效果相同时不会重复显示。
- 英雄的技能强化单列在“技能强化”，可直接比较强化前后说明与任务编号。

## 管理英雄与助手标签

普通查询仍可直接双击打开 `quickref/index.html`。要维护公共英雄或助手标签，可直接双击项目根目录的 `启动标签管理.bat`；它会打开仅本机可访问的统一管理页，默认显示英雄，右上角可切换助手。关闭其命令窗口即可停止服务。也可以在项目根目录手动启动：

~~~powershell
uv run python scripts\tag_admin.py
~~~

浏览器打开 `http://127.0.0.1:8787/`。管理页可维护任意层级的标签树，并为每张英雄卡或每名助手勾选多个叶子标签；保存会立即重建 `data/quickref_catalog.json` 与离线查询页。英雄使用独立的空白配置 `data/hero_tags.json`，助手继续使用原有的 `data/assistant_tags.json`；两套标签、归属和筛选互不混用。

删除标签会先提示受影响的英雄或助手数；确认后会同时删除该标签（及其子标签）和对应归属。标签配置为公共数据，提交或共享项目时请一并保留两份 JSON。

## 更新本地数据

在 MuMu 已打开 Live A Hero 且设备通过 adb devices 显示为 device 后，手动执行导入：

~~~powershell
C:\Python314\python.exe scripts\import_lah_snapshot.py --serial <设备序列号>
~~~

这一步只读取游戏公开目录中的 ChineseSimplified、CardMaster、SidekickMaster 和 SkillMaster，并保存为同一标签的本地快照。

接着一并重建离线网页、目录数据和 Excel：

~~~powershell
C:\Python314\python.exe scripts\lah_quickref.py --xlsx outputs\Live_A_Hero_本地速查.xlsx
~~~

该命令会通过本项目的 Excel 构建器生成四张筛选表；如果提示找不到 @oai/artifact-tool，请在 Codex 工作区内运行，以使用其自带的表格运行环境。速查数据只采用官方简中；缺失名称或说明会保留日文，并标为“日文原文”。
