# LW-WIKI-Bot 部署与使用文档

一个基于 NapCat + NoneBot2 的 QQ 群聊 Wiki 查询机器人，主要面向《Live A Hero》《housamo》等游戏，在群里当作快速查询 wiki 使用。

本文档记录了整个项目的技术方案、搭建流程、数据来源、启动方式和维护方法。

---

## 一、整体架构

QQ 机器人由两半组成，通过 OneBot v11 标准协议对接：

```
QQ服务器 <——> NapCat（协议端，登录QQ收发消息） <——WebSocket——> NoneBot2（机器人逻辑） <——> 本地/在线数据
```

- **协议端 NapCat**：负责用一个 QQ 号登录、收发消息。它是"手"和"嘴"。
- **机器人框架 NoneBot2**：负责"收到什么消息、回复什么"的业务逻辑。它是"大脑"。
- **两者通过 WebSocket 连接**：NapCat 主动连到 NoneBot 的 `ws://127.0.0.1:8080/onebot/v11/ws`，用 token 校验。

> 风险提示：NapCat 属于第三方协议端，违反腾讯用户协议，有封号风险。务必使用小号，不要绑定重要资料，不要群发广告或高频刷屏。

## 五、数据来源（重要）

### 5.1 Live A Hero —— 有开源数据库

数据来自开源社区仓库 `liveahero-community/translations`（GitHub），无反爬、可直接下载。

- **数值/结构数据完整**：201 个英雄、2500 条英雄技能（稀有度、技能、成长等），主体为**日文**。
- **中文名现状**：该社区尚未把游戏中文文本导入解包数据，因此没有系统的中文角色名/技能名。中文只有部分技能翻译（约16%）和角色背景故事（`detail.properties`）。
- **应对方案**：日文名为主 + `aliases.json` 中文别名表。查询时中日文都能命中，别名由你和群友逐步补充。

生成数据的命令：

```powershell
uv run python scripts/fetch_lah.py
```

脚本会自动取最新版本，下载英雄+技能数据和中文翻译，合并写入 `data/lah_data.json`。

### 5.2 想要完整官方中文名 —— 需自己解包

游戏本体支持中文，但要拿到官方中文名需自己解包中文客户端（Unity 手游）：

1. 获取中文安卓客户端 `.apk`
2. 解压（APK 本质是 zip），资源在 `assets/`
3. 用 `UnityPy` 或 AssetStudio 提取 TextAsset/MonoBehaviour
4. 定位中文本地化文件，转成 `{日文名: 中文名}` 映射，写入 `aliases.json`

难点：资源可能加密（AES/UnityCN），或中文是热更新下载（不在 APK 内，需抓 CDN）。属于版权灰色地带，仅自用。

### 5.3 housamo —— 待解决

`wikiwiki.jp/housamo` 有反爬（返回 403 访问确认页），无现成开源库。可选：找其他数据源、手工整理常查内容进 `wiki_local.json`。

## 六、启动与运行

### 6.1 启动 NoneBot（大脑）

开一个终端窗口，执行：

```powershell
$env:Path = "C:\Users\Penguin\.local\bin;$env:Path"
cd E:\AIVC\LW-WIKI-Bot
uv run python bot.py
```

看到 `Uvicorn running on http://127.0.0.1:8080` 表示成功，保持窗口开着。

### 6.2 安装并启动 NapCat（协议端）

1. 从 https://github.com/NapNeko/NapCatQQ/releases 下载 `NapCat.Shell.Windows.OneKey.zip`
2. 解压到无中文路径（如 `E:\AIVC\NapCat`）
3. 运行 `NapCatInstaller.exe` 等待自动配置
4. 进入 `NapCat.XXXX.Shell` 目录，运行 `napcat.bat` 启动
5. 缺 dll 时安装微软 `VC_redist.x64` 运行库

### 6.3 登录与连接配置

1. 浏览器打开 WebUI：http://localhost:6099
2. 用**小号**扫码登录
3. 在「网络配置」添加**反向 WebSocket 客户端**：

| 项目 | 值 |
|------|-----|
| URL | `ws://127.0.0.1:8080/onebot/v11/ws` |
| Token | `lwbot_9f3a7c2e5d` |
| 消息格式 | Array |
| 启用 | 开 |

保存启用后，NapCat 会连上 NoneBot。NoneBot 日志出现 `Bot xxx connected` 即成功。

### 6.4 启动顺序

先启动 NoneBot（占用 8080），再启动 NapCat（主动连接）。反过来 NapCat 会连不上、自动重试。

## 七、使用方法

群里发送：

- `/查 明石` —— 查角色（中文别名命中日文角色）
- `/查 火球术` —— 查技能/条目
- `/帮助` —— 显示用法

支持精确匹配、别名、子串匹配、错别字模糊匹配；查不到时给候选。指令前缀支持 `/`、`#` 或直接发。

## 八、维护

### 8.1 加中文别名

编辑 `data/aliases.json`，格式 `"中文名": "数据中的日文名"`：

```json
{
  "明石": "アカシ",
  "杢代": "モクダイ"
}
```

无需重启，查询时每次重新读取数据。

### 8.2 加手工数据

编辑 `data/wiki_local.json`，格式：

```json
{
  "条目名": {
    "name": "条目名",
    "aliases": ["别名1", "别名2"],
    "content": "内容描述"
  }
}
```

### 8.3 更新 Live A Hero 数据

游戏更新后重新运行 `uv run python scripts/fetch_lah.py` 即可拉取最新数据。
